## §8.3.5 Theorem 8.6 (Lieb-Schultz-Mattis-type theorem without continuous symmetry)

**Tasaki §8.3.5, Theorem 8.6** (statement p. 276; the section runs pp. 276-280) is a **documented axiom** carried by six declarations in `LatticeSystem/Quantum/SpinS/LiebSchultzMattisDiscrete.lean`, **all six of which are axioms** — the module contains no `def`, no `structure` and no `theorem` at all, the same all-axiom shape as `AKLTInfiniteChain.lean` (the [Theorem 7.2 entry](/lattice-system/limitations/documented-axioms/chapter-07/#entry-theorem-7-2)): `IsTranslationInvariantS` (doc comment lines 36-37, declaration line 38), `HasShortRangeHamiltonianS` (doc comment lines 40-45, declaration line 46), `IsZ2Z2SymmetricS` (doc comment lines 48-53, declaration line 54), `IsTimeReversalSymmetricS` (doc comment lines 56-62, declaration line 63), `HasUniqueGappedGroundStateS` (doc comment lines 65-69, declaration line 70), and `tasaki_theorem_8_6` itself (doc comment lines 72-82, declaration lines 83-86).

- **What the axioms literally assert:** the five predicates assert nothing. Each is an uninterpreted `Prop`-valued function `{L N : ℕ} : ManyBodyOpS (Fin L) N → Prop` with no defining equation and no axiom constraining it, so none can be established for any concrete Hamiltonian and none can be refuted; all five admit the interpretation "always false". `tasaki_theorem_8_6` is the no-go implication assembled from them: for `{L N : ℕ}`, `hN : Odd N` (half-odd-integer spin `S = N/2`), `H : ManyBodyOpS (Fin L) N`, `hSR : HasShortRangeHamiltonianS H`, `hTI : IsTranslationInvariantS H` and `hSym : IsZ2Z2SymmetricS H ∨ IsTimeReversalSymmetricS H`, it concludes `¬ HasUniqueGappedGroundStateS H`. Interpreting all five markers as "always false" satisfies the package outright (the hypothesis `hSR` becomes unsatisfiable), so the six declarations add no inconsistency — and, dually, they prove nothing whatsoever about any concrete chain Hamiltonian in this repository. This is the same opaque-marker idiom as the [§8.3.2 markers](/lattice-system/limitations/documented-axioms/chapter-08-part-02/#entry-spt-markers-8-3-2), `IsShortRangeGappedUniqueGS` / `IsProductStateHamiltonian`.
- **Axiom reason (documented) — the book explicitly declines to prove the theorem and defers to an operator-algebraic paper.** Tasaki gives only a heuristic argument (a unique gapped ground state inherits the symmetry of the Hamiltonian, is approximable by a symmetric matrix product state, and this contradicts Corollary 8.5) and then says of that argument, in his own words: "Although the above argument is plausible, there are still some essential mathematical gaps in it, which are not easy to fill. In short one must have a very good control on the approximation by (injective) matrix product states in order to justify the claim, but the currently available results [1, 27] are not enough for the purpose." (p. 277, re-verified directly against the rendered book page, not from the `pdftotext` transcript). The rigorous proof is handed to a separate paper: "But recently Ogata and Tasaki [77] provided a fully rigorous Proof of Theorem 8.6, which does not make use of matrix product approximations. The proof instead makes use of a deep analogy between the Cuntz algebra associated with a pure state with the split property and the matrix product formulation, and is based on closely related results by Matsui [62, 63]." (p. 277, likewise re-verified), where [77] = Y. Ogata, H. Tasaki, *Lieb-Schultz-Mattis type theorems for quantum spin chains without continuous symmetry*, Commun. Math. Phys. **372**, 951-962 (2019), arXiv:1808.08740, and [62], [63] = T. Matsui, *A characterization of finitely correlated pure states*, Infin. Dimens. Anal. Quantum Probab. **1**, 647-661 (1998) and *The split property and the symmetry breaking of the quantum spin chain*, Commun. Math. Phys. **218**, 393-416 (2001) (all three verified against the printed Chapter 8 bibliography). The proof therefore lives entirely in the infinite-chain operator-algebraic setting — pure states on the quasi-local C\*-algebra, the split property, the associated Cuntz algebra — which is the deferral class of Appendix A.21-A.28 of the [documented-axiom policy](/lattice-system/limitations/documented-axioms/), the [Theorem 7.2 entry](/lattice-system/limitations/documented-axioms/chapter-07/#entry-theorem-7-2) and the [§8.3.2 markers](/lattice-system/limitations/documented-axioms/chapter-08-part-02/#entry-spt-markers-8-3-2). Two consequences are recorded rather than glossed: (a) the "prove theorems Tasaki cites without proof" rule does not override this entry, because its standing exception is exactly the genuine C\*-algebra/GNS framework; and (b) the marker predicates are opaque for the same reason as the §8.3.2 markers — their faithful forms are infinite-chain notions, and the repository has no layer in which they could be written down. As with §8.3.2, infinite/thermodynamic-limit systems are explicitly **in** scope as a long-term project goal, so this is not an "out of scope" marker: what is absent is the constructed quasi-local C\*-algebra layer for the spin chain (`QuasiLocalRealization`, `LatticeSystem/Quantum/SpinS/QuasiLocalRealization.lean`, line 40, still bundles the inductive-limit identification as the hypothesis fields `boxTower_exhausts_localAlg` and `boxTower_closure_is_quasiLocalAlgebra`, lines 46 and 48, rather than constructing it).
- **The repository's discharged §6.2 theorem is technically discontinuous with this one, by the book's own statement.** Tasaki introduces Theorem 8.6 with: "Unlike the original Lieb-Schultz-Mattis theorem (see Sect. 6.2), which makes an essential use of the U(1) symmetry, the following statement assumes only discrete symmetry." (p. 276, re-verified against the rendered page). The repository's §6.2 development is fully discharged and axiom-free — `lieb_schultz_mattis_affleck_lieb` (`LatticeSystem/Quantum/SpinS/LiebSchultzMattisRingGap.lean`, line 64), the finite-volume variational + Courant-Fischer route built on the U(1) twist operator `lsmTwistOperator` (`LiebSchultzMattis.lean`, line 49, eq. (6.2.2)) — but it supplies **no route** to Theorem 8.6: its mechanism is the U(1)-twisted trial state, which does not exist when only a discrete symmetry is assumed. Reusing the §6.2 machinery here is therefore not an available shortcut, and no such reuse is claimed.
- **Faithfulness caveat (recorded, not hidden): a naive finite-`L` reading of the markers would make the axiom false.** The printed theorem is a statement about *the chain* — Ogata-Tasaki prove it for a pure state with the split property on the infinite chain — whereas `tasaki_theorem_8_6` is typed at a fixed finite `L` (`H : ManyBodyOpS (Fin L) N`). Suppose the markers were given their obvious finite-`L` readings ("`H` commutes with the chain translation", "`H` is a sum of nearest-neighbour terms", "`H` is time-reversal symmetric", "the lowest eigenvalue of `H` is simple and lies strictly below the rest of the spectrum"). Then the conclusion `¬ HasUniqueGappedGroundStateS H` would be refuted by this repository's own §6.2 results: for even `L ≥ 2` and odd `N`, the spin-`S` antiferromagnetic Heisenberg ring `afmHeisenbergChainHamiltonianS L N` — nearest-neighbour, translation invariant and `SU(2)`-symmetric, hence a fortiori Z₂ × Z₂-symmetric (the three π rotations lie in `SU(2)`), and time-reversal symmetric as well, the latter *not* by a fortiori reasoning from `SU(2)` invariance (which does not in general imply invariance under the antiunitary time reversal: the `SU(2)`-invariant scalar chirality `Ŝ₁·(Ŝ₂ × Ŝ₃)` is odd under it) but because this particular Hamiltonian is a real-coefficient sum of the bilinear terms `Ŝ_x · Ŝ_y`, each even under time reversal; in any case only the Z₂ × Z₂ disjunct is needed, `hSym` being a disjunction — has a ground eigenspace of `finrank ≤ 1` (`afm_ring_ground_state_data`, `LiebSchultzMattisRingGroundData.lean`, line 30) *and* a strictly positive spectral gap `IsPositiveSpectralGap` bounded by `8π²S²/L` (`lieb_schultz_mattis_affleck_lieb`, above), both proved axiom-free. There is no contradiction with the book: the LSM bound makes that gap vanish as `L ↑ ∞`, which is exactly why the theorem's "nonzero gap" must be read in the infinite-volume sense. **Keeping all five markers opaque is the recorded design reason, not an oversight; this refutation is not itself formalized here** (no Lean proof that a finite-`L` reading is inconsistent is claimed or asserted), and any future discharge must supply the infinite-chain readings rather than finite-`L` substitutes.
- **Consumers:** freshly re-verified (`grep -rn` over `LatticeSystem/`): all six names occur only inside `LiebSchultzMattisDiscrete.lean` as their own doc comments, declarations and the hypotheses/conclusion of `tasaki_theorem_8_6` (lines 83-86), plus three doc-comment cross-references from modules that do **not** import this one — `HasShortRangeHamiltonianS` and `HasUniqueGappedGroundStateS` are named once each in `SPTPhase.lean:75` (recording the deliberate scope split from the `N = 2` bundled marker `IsShortRangeGappedUniqueGS`), `IsZ2Z2SymmetricS` once in `KennedyTasakiTransformation.lean:410` (recording that it is a deliberately different object from the concrete `S = 1` definition `IsZ2Z2Invariant`), and `IsTimeReversalSymmetricS` twice in `SPTTopologicalIndex.lean` (lines 38 and 68). `tasaki_theorem_8_6` occurs only at its own declaration. No proved result depends on any of the six. (Repository-wide, `tex/proof-guide.tex` names them in prose in its §8.3.5 paragraph and the legacy catalogue carries the row; neither is a Lean consumer.) The `IsTimeReversalSymmetricS` / `IsTimeReversalInvariant` duplication is **not** re-litigated here: it is already recorded at the end of the [§8.3.3 entry](/lattice-system/limitations/documented-axioms/chapter-08-part-02/#entry-entanglement-entropy-8-3-3) as a knowingly parallel pair.

## §8.3.6 Theorem 8.8 (rigorous index theorem and the SPT phase transition)

**Tasaki §8.3.6, Theorem 8.8** (statement p. 281, for the interpolation eq. (8.3.55) on the same page; the section "Rigorous Index Theorems for SPT Phases" runs pp. 280-287) contributes four **documented axioms** in `LatticeSystem/Quantum/SpinS/SPTPhaseTransition.lean`: `IsGaplessInInfiniteVolume` (doc comment lines 48-51, declaration line 52), `HasMultipleGroundStatesInInfiniteVolume` (doc comment lines 54-56, declaration line 57), `HasLocalExpectationDiscontinuityInInfiniteVolume` (doc comment lines 59-61, declaration line 62) and `tasaki_theorem_8_8` itself (doc comment lines 64-74, declaration lines 75-80). The model the theorem is about is **not** axiomatized: `sptInterpolatingHamiltonianS` (doc comment lines 40-43, declaration lines 44-46) is a real `def`.

- **What the axioms literally assert:** the three predicates assert nothing. Each is an uninterpreted `Prop`-valued function of a *family* of finite-volume Hamiltonians, `(H : (L : ℕ) → ManyBodyOpS (Fin L) 2) : Prop`, with no defining equation and no axiom constraining it; the family argument is what carries the intended `L ↑ ∞` reading, since none of the three is a property of any fixed `L`. `tasaki_theorem_8_8` states `∃ s : ℝ, 0 < s ∧ s < 1 ∧ (IsGaplessInInfiniteVolume (fun L => sptInterpolatingHamiltonianS L s) ∨ HasMultipleGroundStatesInInfiniteVolume (fun L => sptInterpolatingHamiltonianS L s) ∨ HasLocalExpectationDiscontinuityInInfiniteVolume (fun L => sptInterpolatingHamiltonianS L s))`, i.e. the book's three-way disjunction at an intermediate `s`, kept faithfully as a disjunction rather than strengthened to gaplessness. Because the three markers are opaque, interpreting any one of them as "always true" satisfies the axiom outright, so it adds no inconsistency — and, dually, it proves nothing about the interpolating model.
- **The interpolating Hamiltonian is a real definition and is faithful to (8.3.55):** `sptInterpolatingHamiltonianS L s = (s : ℂ) • akltHamiltonianS L + ((1 - s : ℝ) : ℂ) • ∑ x, spinSSiteOp3 x 2 * spinSSiteOp3 x 2`, where `akltHamiltonianS L = ∑ x, ∑ y, ringCoupling L x y • (spinSDot x y 2 + (1/3) • (spinSDot x y 2 * spinSDot x y 2))` (`LatticeSystem/Quantum/SpinS/AKLT.lean`, doc comment lines 43-46, declaration lines 47-49) and `ringCoupling` (`ShastryNoSSB.lean`, line 42) is the nearest-neighbour ring coupling. This is literally `s ∑_x {Ŝ_x·Ŝ_{x+1} + ⅓(Ŝ_x·Ŝ_{x+1})²} + (1−s) ∑_x (Ŝ_x^{(3)})²` with no constant offset and no rescaling — the printed (8.3.55), re-verified against the rendered book page (p. 281) — so the axiom is anchored to a genuine object rather than to a marker Hamiltonian, and `s = 0` / `s = 1` really are the trivial (8.1.2) and AKLT (7.1.1) endpoints.
- **Axiom reason (documented) — the recorded reason is a missing layer, not the words "infinite volume".** Everything the theorem asserts is carried by the three predicates, and each of them is a property of the `L ↑ ∞` limit: gaplessness of the limiting dynamics, multiplicity of infinite-volume ground states, and discontinuity in `s` of an infinite-volume ground-state expectation of a local observable. This repository has **no layer in which those three notions can be defined at all**. The abstract pieces that exist are the C\*-algebraic Definitions A.25/A.27 (`IsGroundState` and `HasNonzeroGap`, `LatticeSystem/Math/CStarAlgebra/GroundState.lean`, lines 37 and 43) together with `IsState` (`State.lean`, line 37); what is missing is everything that would connect a *family of finite-volume matrices* to them — a constructed quasi-local C\*-algebra of the spin chain and a weak-\* limit of the finite-volume states. `QuasiLocalRealization` (`LatticeSystem/Quantum/SpinS/QuasiLocalRealization.lean`, line 40) stops exactly short of this: it bundles the inductive-limit identification as the hypothesis fields `boxTower_exhausts_localAlg` and `boxTower_closure_is_quasiLocalAlgebra` (lines 46 and 48) instead of constructing it, and supplies neither an infinite-volume ground-state set nor a gap nor an expectation functional depending on a parameter `s`. **This is the reason to record, and it is not "infinite volume is out of scope":** infinite/thermodynamic-limit systems are an explicit long-term goal of this project (the same point made for the [§8.3.2 markers](/lattice-system/limitations/documented-axioms/chapter-08-part-02/#entry-spt-markers-8-3-2)), and the deferral here would end the moment the defining layer existed. Separately, Tasaki gives no proof of Theorem 8.8 in the book either: "The theorem was proved by Tasaki in 2018 as a corollary of his index theorem [94]. See below. Ogata's general index theorems [75, 76] lead to a similar (slightly weaker) conclusion for the model (8.3.55)." (p. 281, re-verified against the rendered page), where [94] = H. Tasaki, *Topological phase transition and Z₂ index for S = 1 quantum spin chains*, Phys. Rev. Lett. **121**, 140604 (2018), arXiv:1804.04337, and [75], [76] = Y. Ogata's two Z₂-index preprints, arXiv:1810.01045 (2018) and arXiv:1904.01669 (2019) (all verified against the printed Chapter 8 bibliography). The sketch he does give — "Tasaki's Proof of Theorem 8.8 is based on an elementary index theorem. By making use of an earlier observation by Nakamura and Todo [71], Tasaki defined a Z₂ index for a unique gapped ground state in spin chains with certain symmetry. By proving the invariance of the index under continuous modification of the model, the existence of a phase transition between the trivial phase and the Haldane phase was proved." (p. 282, re-verified) — presupposes exactly the missing layer, since the index is attached to an infinite-volume unique gapped ground state and the argument is its invariance along the path. This entry therefore belongs to the operator-algebra / infinite-volume deferral class of Theorem 7.2 and the §8.3.2 markers, not to the "external source inaccessible" class of Theorem 7.7: source access is not the obstacle, [94] being openly available as arXiv:1804.04337.
- **Faithfulness caveats (recorded, not hidden):**
  1. The printed theorem asks for "an intermediate value of `s`" with `s ∈ [0, 1]`; the Lean statement reads this as `0 < s ∧ s < 1`, which is the natural reading but is a Lean-side sharpening of the word "intermediate".
  2. The Lean family is `fun L => sptInterpolatingHamiltonianS L s` over **all** `L : ℕ`, including the degenerate `L = 0, 1, 2` that the book's periodic chain does not intend. This is inert while the markers are opaque, but a discharge would have to restrict the tower rather than inherit it.
  3. Tasaki's own proof route carries a hypothesis the theorem statement does not advertise: "The types of symmetry assumed in the theory are precisely (S1), (S2), and (S3) (see p. 256) identified by Pollmann, Turner, Berg, and Oshikawa [81, 82], but with an additional U(1) symmetry. The need of extra U(1) symmetry shows the limitation of this elementary approach. Ogata's index theorems, on the other hand, do not require any symmetry other than (S1), (S2), or (S3)." (p. 282, re-verified). The model (8.3.55) does have that U(1) symmetry, so Theorem 8.8 as printed is unaffected; the point matters only for a future transcription, which must choose between [94] (elementary, needs U(1)) and [75, 76] (no extra symmetry, slightly weaker conclusion).
- **Consumers:** freshly re-verified (`grep -rn` over `LatticeSystem/`): all four axiom names occur only inside `SPTPhaseTransition.lean` — `IsGaplessInInfiniteVolume` at lines 48, 52, 68 and 77; `HasMultipleGroundStatesInInfiniteVolume` at 54, 57, 70 and 78; `HasLocalExpectationDiscontinuityInInfiniteVolume` at 60, 62, 72 and 79; `tasaki_theorem_8_8` only at its own declaration (line 75) — and `sptInterpolatingHamiltonianS` likewise occurs only in this module (declaration line 44, then lines 77, 78 and 80). No proved result depends on any of them, and the definition has no consumer either. (Repository-wide the names also appear in `tex/proof-guide.tex` lines 17128, 17131 and 17133-17135 as `\texttt{}` prose references and in the legacy catalogue row; neither is a Lean consumer.)
- **Re-check condition:** the disposition would change only when all three of the following exist in reviewed form in this repository (or are usable from `mathlib`): (a) a constructed quasi-local C\*-algebra of the spin chain on `ℤ` with a weak-\* limit construction taking a family of finite-volume ground states to an infinite-volume state — the same item (a) as the [§8.3.2 markers](/lattice-system/limitations/documented-axioms/chapter-08-part-02/#entry-spt-markers-8-3-2), the [Theorem 7.2 entry](/lattice-system/limitations/documented-axioms/chapter-07/#entry-theorem-7-2) and the Theorem 8.6 entry above; (b) infinite-volume definitions replacing the three markers (gaplessness of the limiting dynamics via Definition A.27, multiplicity of ground states via Definition A.25, and continuity in `s` of the ground-state expectation of a local observable), so that the disjunction says something; and (c) a math-before-code transcription of Tasaki [94] — including the Z₂ index itself, whose one already-available ingredient is recorded here: footnote 55 (p. 282, re-verified) states that "The index is essentially the sign of the expectation value of the Lieb-Schultz-Mattis U(1) twist operator (6.2.2)", and that twist operator exists in this repository as the real definition `lsmTwistOperator` (`LatticeSystem/Quantum/SpinS/LiebSchultzMattis.lean`, line 49, eq. (6.2.2)) — or of Ogata [75, 76] for the weaker conclusion. Partial progress on (a) or on the index formula alone does not reopen this entry, since without (b) the theorem's conclusion cannot even be stated.

## §8.4 Theorem 8.9 (stability of the toric code's topological order under arbitrary local perturbations)

**Tasaki §8.4, Theorem 8.9** (statement p. 296; the perturbed model (8.4.19) and its hypotheses are set up at the foot of p. 295, and §8.4 runs pp. 288-297) is a **documented axiom** carried by three declarations in `LatticeSystem/Quantum/SpinS/ToricCode.lean`: `IsToricPerturbation` (doc comment lines 95-97, declaration lines 98-99), `HasFourNearlyDegenerateGroundStates` (doc comment lines 101-104, declaration lines 105-106) and `tasaki_theorem_8_9` itself (doc comment lines 108-117, declaration lines 118-123). The *model* is not axiomatized: the torus edge set, the stabilizers and both Hamiltonians are real definitions — `ToricEdge` (line 51), `starEdges` (lines 55-56), `plaquetteEdges` (lines 60-61), `sigmaZS` / `sigmaXS` (lines 64-65 and 68-69), `starOperatorS` (lines 73-75), `plaquetteOperatorS` (lines 79-81), `toricCodeHamiltonianS` (lines 87-88) and `perturbedToricHamiltonianS` (lines 91-93) — so the axiom is anchored to genuine objects, the same shape as the Theorem 8.8 entry above and unlike the all-axiom modules of Theorem 7.2 and Theorem 8.6.

- **What the axioms literally assert:** the two predicates assert nothing. `IsToricPerturbation (L : ℕ) [NeZero L] (r : ℕ) (V : ToricEdge L → ManyBodyOpS (ToricEdge L) 1) : Prop` and `HasFourNearlyDegenerateGroundStates {Λ : Type} [Fintype Λ] [DecidableEq Λ] (H : ManyBodyOpS Λ 1) (Δ : ℝ) : Prop` are uninterpreted `Prop`-valued function symbols with no defining equation and no axiom constraining them, so neither can be established for any concrete operator and neither can be refuted. `tasaki_theorem_8_9 (r : ℕ)` is the stability statement assembled from them: `∃ ε₀ Δ : ℝ, 0 < ε₀ ∧ 0 < Δ ∧ ∀ ε : ℝ, |ε| ≤ ε₀ → ∀ (L : ℕ) [NeZero L], 2 ≤ L → ∀ V, IsToricPerturbation L r V → HasFourNearlyDegenerateGroundStates (perturbedToricHamiltonianS L ε V) Δ`. Interpreting `HasFourNearlyDegenerateGroundStates` as "always true" (or `IsToricPerturbation` as "always false") satisfies it outright with `ε₀ = Δ = 1`, so the three declarations add no inconsistency — and, dually, they prove nothing whatsoever about the toric code. This is the same opaque-marker idiom as the [§8.3.2 markers](/lattice-system/limitations/documented-axioms/chapter-08-part-02/#entry-spt-markers-8-3-2) and the §8.3.5 and §8.3.6 entries above.
- **Both Hamiltonians are real definitions and faithful to (8.4.1) and (8.4.19):** the printed Hamiltonian is `Ĥ_tc := −Σ_{v∈V} ∏_{x∈A_v} σ̂_x^{(3)} − Σ_{p∈P} ∏_{x∈B_p} σ̂_x^{(1)}` with `σ̂_x^{(α)} = 2 Ŝ_x^{(α)}` (p. 289, re-verified directly against the rendered book page), and `toricCodeHamiltonianS L = -(∑ v, starOperatorS L v) - ∑ p, plaquetteOperatorS L p` with `starOperatorS L v = ((starEdges L v).toList.map sigmaZS).prod`, `sigmaZS e = (2 : ℂ) • spinSSiteOp3 e 1` (and dually for the plaquettes with `sigmaXS`). The edge set `ToricEdge L = (ZMod L × ZMod L) × Fin 2` is a vertex together with a direction, so `|E| = 2L²`, matching the book's set `E` of bond centres of the `L × L` periodic square lattice (Fig. 8.14, p. 289); `starEdges L v = {(v, 0), ((v.1 - 1, v.2), 0), (v, 1), ((v.1, v.2 - 1), 1)}` and `plaquetteEdges L p = {(p, 0), ((p.1, p.2 + 1), 0), (p, 1), ((p.1 + 1, p.2), 1)}` are exactly the four bonds incident to `v` and the four bonds of the unit square at `p` (Fig. 8.15, p. 289). The four-factor products are `List.prod` over `Finset.toList`, whose enumeration order is immaterial because the factors act on distinct edges and commute. The perturbed model `perturbedToricHamiltonianS L ε V = toricCodeHamiltonianS L + (ε : ℂ) • ∑ x : ToricEdge L, V x` is literally the printed `Ĥ_ε = Ĥ_tc + ε Σ_{x∈E} V̂_x` of (8.4.19) (p. 295, re-verified), with no offset and no rescaling.
- **Axiom reason (documented) — Tasaki gives no proof and hands the theorem to three external papers.** After setting up (8.4.19) he writes: "Then the following is proved in [9, 11, 65]." (p. 295, re-verified directly against the rendered book page, not from the `pdftotext` transcript), where [9] = S. Bravyi, M. B. - **Faithfulness caveats (recorded, not hidden):**
  1. **`Δ` is quantified uniformly in `ε`, and both `ε₀` and `Δ` uniformly in the perturbation family `V`, as well as in `L`.** The printed statement reads: "There exists a constant `ε₀ > 0`, and for any `|ε| ≤ ε₀` and any `L`, the Hamiltonian (8.4.19) has four near degenerate "ground states" whose energies are separated from other energy eigenvalues by a nonzero constant independent of `L`." (p. 296, re-verified directly against the rendered book page). The separation constant is asserted independent of `L`, but it sits under "for any `|ε| ≤ ε₀`", so the printed sentence leaves room for it to depend on `ε`; the Lean statement puts `Δ` outside both `∀ ε` and `∀ L` and is therefore strictly stronger. (Both `ε₀` and `Δ` may depend on the range `r`, which is a parameter of the axiom — matching the printed "the range `r` is a fixed constant".) The same literal strengthening happens in the `V` direction: the printed set-up fixes the family `V̂_x` first ("Consider the perturbed toric code Hamiltonian … where `V̂_x` is a function of `σ̂_y^{(α)}` …", p. 295) and only afterwards asserts "There exists a constant `ε₀ > 0`", so as printed both constants may depend on the family chosen, whereas in Lean `∀ V` sits *inside* `∃ ε₀ Δ` (`ToricCode.lean`, lines 118-123), making them uniform over all range-`r` families at once. This is the same class of caveat as the [Theorem 8.1 entry](/lattice-system/limitations/documented-axioms/chapter-08-part-01/#entry-theorem-8-1)'s `C`/`ξ` uniformity: any future discharge must re-derive the `ε`- and `V`-uniformity rather than assume it.
  2. **`2 ≤ L` is a Lean-side restriction** absent from the printed "any `L`". It excludes only the degenerate `L = 1`, where the four listed edges collapse — in `ZMod 1` one has `v.1 - 1 = v.1` and `p.2 + 1 = p.2`, and a `Finset` literal deduplicates, so the "four-edge" star and plaquette become two-factor products — a case the book's construction (Fig. 8.14, p. 289) does not intend; `L = 0` is already excluded by `[NeZero L]`.
  3. **Nothing requires the perturbation to be self-adjoint.** `V : ToricEdge L → ManyBodyOpS (ToricEdge L) 1` is an arbitrary matrix family, and neither the marker nor the axiom asks for `(V x).IsHermitian`, so `perturbedToricHamiltonianS L ε V` need not be a Hamiltonian at all. What the book prints is only "where `V̂_x` is a function of `σ̂_y^{(α)}` with `y` such that `|y − x| ≤ r`, where the range `r` is a fixed constant. We require that `‖V̂_x‖ ≤ 1` for any `x`." (p. 295, re-verified against the rendered page); self-adjointness is **not** printed as a hypothesis and is an inference here from `Ĥ_ε` (8.4.19) being treated as a Hamiltonian — a general function of the Pauli matrices need not be Hermitian (`σ̂^{(1)} + i σ̂^{(2)}` is not). Either way the Lean side carries no hermiticity requirement. This is inert while the marker is opaque (the "always false" reading absorbs it), but a faithful restatement must carry a hermiticity field exactly as the §7.1.3 sibling `IsAKLTPerturbation` does (`AKLTStability.lean`, field `hermitian`, line 51).
  4. **The marker's doc comment adds a word the printed set-up does not have:** it describes the family as "not assumed symmetric or translation-invariant", whereas p. 295 says only "We do not assume translation invariance" (re-verified against the rendered page). "Symmetric" has no printed counterpart.
  5. The printed theorem writes "ground states" **in quotation marks** — the four states are not exact ground states but a low-energy cluster. The Lean name `HasFourNearlyDegenerateGroundStates` drops the quotes, though its doc comment reads the quantity correctly as a "four-dimensional cluster of near-degenerate low-energy states"; the point matters only for a future restatement.
